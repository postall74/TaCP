## Подтверждённое поведение auth-v2

- anonymous и invalid JWT получают пустой 401 на register;
- manager и engineer получают пустой 403;
- для каждого отказа неизменны counts `AspNetUsers`, `AspNetRoles`,
  `AspNetUserRoles`;
- bootstrap admin входит через anonymous login; `expiresAt` — JSON number unix-ms;
- admin создаёт manager, engineer и admin; каждый пользователь входит и получает
  назначенную роль;
- короткий пароль и duplicate email возвращают 400 с массивом `errors`, без
  изменений counts Identity-таблиц;
- исходный admin JWT после всех операций по-прежнему проходит `/api/auth/me`.

Первый smoke-run остановился на создании второго admin из-за совпадения
synthetic email с bootstrap email. Это дефект harness, не продукта; изменён только
тестовый email, новая БД создана заново, полный повтор дал 21/21.
