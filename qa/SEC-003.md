## Браузерная проверка

Проверка выполнена на production build (`dist`, localhost) с детерминированной
QA-fixture `qa/sec003_mock_api.py`. Fixture возвращает немедленную ошибку
`FRESH_CURRENT_REMOTE_ERROR` либо отложенную на 1,5 секунды
`LATE_OLD_REMOTE_ERROR`.

В светлой и тёмной темах подтверждено:

1. Ошибка текущего remote-submit отображается и остаётся на форме.
2. При очистке URL remote → local отображавшаяся ошибка сразу исчезает.
3. Если remote-submit остаётся pending, очистка URL переключает форму в local;
   поздний reject старого запроса не возвращает ошибку.
4. В local-режиме снова доступна регистрация.

Дополнительно в тёмной теме создан локальный пользователь
`qa-sec003@example.test`, после чего вход этим пользователем успешно открыл
Dashboard. Локальный вход администратором также успешно выполнен при подготовке
темы.
