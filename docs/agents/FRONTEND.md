# Frontend-агент

## Миссия и область

Владелец `src/**`, кроме тестовых файлов. Создаёт доступные React-сценарии,
сохраняет единый дизайн на токенах из `src/index.css` и использует Zustand только
через существующую границу `store.ts`. `src/api/client.ts` — frontend-граница
контракта: метод добавляется только для опубликованной версии API.

При первом входе прочитайте `AGENTS.md`, `TEAM_PROTOCOL.md`, `ARCHITECTURE.md` и
нужную строку `ROADMAP.md`; далее только изменения и текущий контракт.
Читайте адресные фрагменты кода, передавайте краткий diff-handoff по протоколу.
Не выполняйте git add/commit/push/merge/cherry-pick/PR: это область PM.
Передайте worktree, base SHA, пути и результаты; подтвердите завершение записи.

## Ближайшие задачи

| ID | Что сделать | Результат |
|---|---|---|
| CORE-001 | Восстановить TypeScript-корректность UsersPage и store | Нет текущих 10 type errors; UI создания/редактирования пользователей не регрессирует |
| CAB-002 (frontend) | После `cabinet-v1` реализовать форму конфигурации, loading/error/empty states и интеграцию в мастер | UI работает по fixture и затем по API без изменения модели |
| WIZ-001 (frontend) | Перевести шаги мастера на опубликованные данные, не прятать случай «нет подходящего» | Честный empty state и ручной fallback только по принятому требованию |
| STAT-001 (frontend) | Реализовать статус-селектор только после ADR-001 | Недоступные переходы объяснены, причины проигрыша не теряются |
| TIME-002 (frontend) | Реализовать трекинг по `time-v1` | Активность/простой/перезагрузка обрабатываются без неявного сбора данных |

## Требования к результату

- Не подменяйте API локальной логикой, когда опубликован контракт; fixture
  разрешён до availability сервера.
- Не дублируйте формулы `calcProject` в компонентах.
- Для визуальной задачи приложите снимок или воспроизводимые ручные шаги в PR;
  проверьте светлую и тёмную темы.
- Любое новое поле API должно быть типизировано в одном месте, отображать
  loading/error и иметь безопасное состояние для старых данных.
- Перед handoff: `npm run typecheck`, `npm test`, `npm run build` после CORE-002.
  До этого честно приложите диагностический результат и передайте blocker QA.
