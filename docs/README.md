# Документация ТКП·Про

Это единственная актуальная точка входа для команды. Документы разделяют
подтверждённое кодом состояние, будущие требования и правила совместной работы.
Не смешивайте их в одном файле.

| Документ | Для чего читать |
|---|---|
| [CURRENT_STATE.md](CURRENT_STATE.md) | Что есть в репозитории и что реально прошло проверку на 22.09.2026 |
| [ARCHITECTURE.md](ARCHITECTURE.md) | Границы модулей, контракты и технические инварианты |
| [ROADMAP.md](ROADMAP.md) | Приоритетный план с владельцами, зависимостями и критериями приёмки |
| [TEAM_PROTOCOL.md](TEAM_PROTOCOL.md) | Как четыре агента работают параллельно без конфликтов |
| [DECISIONS.md](DECISIONS.md) | Решения, которые нельзя принимать молча в feature-ветке |
| [agents/FRONTEND.md](agents/FRONTEND.md) | Зона ответственности и первые задачи frontend-агента |
| [agents/BACKEND.md](agents/BACKEND.md) | Зона ответственности и первые задачи backend-агента |
| [agents/QA.md](agents/QA.md) | Зона ответственности и первые задачи QA-агента |
| [agents/PM.md](agents/PM.md) | Зона ответственности руководителя проекта |

`README.md` — обзор для человека. `QUICKSTART.md` — ручной локальный запуск.
`backend/MIGRATIONS.md` — рабочие команды EF Core. Прежние `DOCS.md` и
`TODOList.md` оставлены как совместимые входные точки и направляют сюда; они не
являются отдельными источниками требований.
