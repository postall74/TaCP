## 📝 Примечания для разработчиков

*   **Язык коммитов:** Все сообщения коммитов должны быть на **русском языке**.
    *   ❌ Плохо: `Fix user position bug`
    *   ✅ Хорошо: `Исправлено отображение должности в профиле пользователя`
*   **Ветвление:** Название ветки должно соответствовать задаче (см. выше).
*   **Стили:** При правке UI всегда использовать токены темы (`bg-card`, `text-ink`), а не жесткие цвета (`bg-white`, `text-black`), чтобы поддерживать светлую/темную тему.
